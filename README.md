# car-ts-audio-fix

CLI-утилита на Python 3.11+ для подготовки видеофайлов под автомагнитолы, у которых звук стабильно работает только в контейнере MPEG-TS (`.ts`).

## Проблема

Некоторые магнитолы показывают видео, но не воспроизводят звук, если контейнер/кодек аудио «не нравится» устройству. Этот проект принудительно делает выход **всегда `.ts`** и создает «железно-совместимую» аудиодорожку.

## Почему по умолчанию MP2 + stereo + 48kHz

- `MP2` в TS часто поддерживается даже старыми устройствами.
- `2 канала` (downmix) снижают риск проблем с 5.1.
- `48kHz` — типичный стандарт для видео/TS.

По умолчанию:
- видео: `-c:v copy` (быстро и без потерь);
- аудио: первая дорожка, транскодирование в MP2 (`192k`, `48000`, `2ch`);
- контейнер: всегда `-f mpegts` и расширение `.ts`.

## Установка ffmpeg

Проверьте, что `ffmpeg` и `ffprobe` доступны:

```bash
ffmpeg -version
ffprobe -version
```

Если не установлены — поставьте пакетным менеджером вашей ОС.

## Установка проекта

```bash
pip install -e .
```

После этого доступны:
- `car-ts-audio-fix ...`
- `python -m car_ts_audio_fix ...`

## Быстрый старт

### Один файл

```bash
car-ts-audio-fix /path/video.mkv
```

### Папка рекурсивно

```bash
car-ts-audio-fix /path/videos --recursive --jobs 4
```

### Выбрать аудиодорожку

```bash
car-ts-audio-fix movie.mkv --audio-track 1
```

### Конвертировать все аудиодорожки

```bash
car-ts-audio-fix movie.mkv --all-audio
```

### Совместимость-тест (3 коротких файла)

```bash
car-ts-audio-fix movie.mkv --compat-test --test-seconds 20
```

Создаст:
- `movie.test_mp2.ts`
- `movie.test_ac3.ts`
- `movie.test_aac.ts`

### AAC в TS и LATM

Некоторые устройства ожидают LATM-пакетизацию AAC в TS:

```bash
car-ts-audio-fix movie.mkv --audio-codec aac --aac-latm
```

Для `--compat-test` флаг `--aac-latm` применяется к AAC-варианту теста.

### Safe-video (максимальная совместимость видео)

Если видео не воспроизводится на магнитоле, включите безопасный режим:

```bash
car-ts-audio-fix movie.mkv --safe-video
```

Видео перекодируется в H.264 baseline (`yuv420p`, level 3.1).

### Dry-run

Показать команды ffmpeg без выполнения:

```bash
car-ts-audio-fix movie.mkv --dry-run
```

## Важные опции

- `--audio-codec mp2|ac3|aac`
- `--audio-bitrate ...` (дефолты: mp2=192k, ac3=384k, aac=192k)
- `--sr 48000` (частота)
- `--ac 2` (каналы)
- `--skip-compatible` — пропускать уже совместимые `.ts`
- `--overwrite` — перезаписывать выходной файл
- `--outdir DIR` — отдельная директория вывода
- `--keep-original-audio` — оставить оригинальные дорожки + добавить совместимую

> ⚠️ Внимание: при `--keep-original-audio` магнитола может выбрать «не ту» дорожку и снова играть без звука. Поэтому по умолчанию эта опция выключена.

## Exit codes

- `0` — успех (включая skip)
- `2` — не найдены `ffmpeg`/`ffprobe`
- `3` — частичные ошибки в batch

## Ограничения и допущения

- Требуется внешняя установка `ffmpeg`/`ffprobe`.
- По умолчанию берется первая видеодорожка и первая аудиодорожка (или выбранная `--audio-track`).
- Для batch-режима ошибки отдельных файлов не останавливают весь запуск.
- В safe-video используется фиксированный baseline-профиль для максимальной совместимости, ценой скорости/качества.

## FAQ

### «Нет звука»

1. Проверьте, что файл действительно `.ts`.
2. Попробуйте `--compat-test` и выберите вариант, который реально звучит на устройстве.
3. Убедитесь, что выбрана правильная аудиодорожка (`--audio-track`).
4. Если исходник 5.1, оставляйте `--ac 2`.

### «Не идёт видео»

Запустите с `--safe-video`, чтобы перекодировать видео в максимально совместимый H.264 baseline.

### «Почему видео не перекодируется по умолчанию?»

Чтобы работать быстро и без потерь качества. Обычно проблема в аудио/контейнере, поэтому по умолчанию видео копируется (`-c:v copy`).
