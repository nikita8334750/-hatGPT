# Логистическая программа для пассажирских перевозок

Эта версия — с **по-настоящему красивым дизайном**, адаптивной мобильной вёрсткой и **моментальным откликом** (операции без перезагрузки страницы).

## Функционал

- 🚍 Визуальный дашборд рейсов в реальном времени;
- 🧭 Построение цепочки маршрутов между городами;
- 👨‍✈️ Фильтрация по водителю;
- 🏙️ Фильтрация по городу;
- 🎟️ Бронирование мест с мгновенным обновлением остатков;
- 📦 Оформление передачек;
- 📊 Метрики в шапке: рейсы, свободные места, бронирования, передачки;
- 📱 Мобильная PWA-версия для iOS и Android (установка на домашний экран).

## Запуск

```bash
python3 app.py
```

Откройте в браузере: `http://localhost:8080`

## Установка на телефон

1. Откройте URL приложения на телефоне в одной сети с сервером.
2. Android (Chrome): меню → «Добавить на главный экран».
3. iOS (Safari): «Поделиться» → «На экран “Домой”».

## Тесты

```bash
python3 -m unittest -v
```
