# W212 Speedometer Program

Полноценная консольная программа для расчёта и отображения показаний спидометра Mercedes-Benz W212 на стенде/в эмуляции.

## Что реализовано

- расчёт скорости из `wheel_rpm` с фильтрацией (EMA);
- подсчёт пробега "после старта";
- учёт времени поездки;
- текущий и средний расход топлива (`л/100км`);
- отображение передачи PRND и внешней температуры;
- 2 режима источника данных:
  - `simulator` (генерация сценария поездки),
  - `csv` (чтение телеметрии из файла).

> Важно: это инженерная программа-эмулятор для тестов и разработки HMI/логики. Для реального подключения к CAN W212 потребуется отдельный аппаратный интерфейс и карта сигналов под конкретную конфигурацию авто.

## Запуск

```bash
python3 w212_speedometer.py --mode simulator --duration 12 --hz 4
```

### Запуск по CSV

```bash
python3 w212_speedometer.py --mode csv --csv-path data/sample_w212_telemetry.csv
```

## Формат CSV

```csv
timestamp,wheel_rpm,fuel_lph,gear,outside_temp_c
0.0,0,0.8,P,6.0
0.1,15,1.2,D,6.0
```
