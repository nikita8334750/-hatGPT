# ЛР3 — спектральная обработка сигналов в MATLAB и Simulink

Репозиторий с материалами для лабораторной работы №3 по дисциплине «Обработка сигналов в Matlab».

## Содержание

- `LR3_variant2_master_updated.m` — основной MATLAB-скрипт для варианта 2.
- `docs/answers_control_questions.md` — ответы на контрольные вопросы.
- `docs/work_instruction.md` — инструкция по выполнению работы.
- `docs/report_structure.md` — структура отчёта и список нужных рисунков.

## Исходный файл данных

Для официального запуска нужен файл варианта:

```text
V_02.mat
```

Внутри файла должны быть переменные:

```text
Fs — частота дискретизации
s  — массив отсчётов сигнала
t  — массив времени
```

Файл `V_02.mat` лучше не хранить в публичном репозитории, если преподаватель выдавал его как учебный материал. Положите его рядом со скриптом локально.

## Запуск

Откройте MATLAB в папке проекта и выполните:

```matlab
LR3_variant2_master_updated
```

После запуска появится папка:

```text
LR3_variant2_output
```

В ней будут графики, численные результаты и данные для отчёта.

## Логика работы

1. Загрузка исходных данных из `.mat`-файла.
2. Построение исходного сигнала во временной области.
3. Вычисление спектра с помощью `fft`.
4. Построение амплитудного спектра.
5. Поиск максимальной спектральной составляющей.
6. Пороговая обработка спектра.
7. Восстановление гармоники через `ifft`.
8. Подготовка данных для SPTool и Simulink.

Для файла `V_02.mat` основной пик спектра получается около 20 Гц.
