# Логистическая программа для пассажирских перевозок

Продвинутая система для водителей и пассажиров: красивый интерфейс, быстрый отклик, расширенная навигация и **самовосстановление при ошибках**.

## Что нового в навигации

- 🧭 **Смарт-навигация маршрута**: пошаговый таймлайн сегментов с пересадками и временем ожидания.
- 🗺️ **Центральная навигационная панель с вкладками**: рейсы, смарт-маршрут, табло отправлений.
- 🛫 **Табло отправлений** по городу с быстрым обновлением.
- ⭐ **Избранные направления** (топ-пары городов).
- 🕘 **История поиска** маршрутов (сохраняется локально).

## Система самовосстановления (self-healing)

- 🩺 При сбое операции сервис автоматически:
  1. фиксирует ошибку,
  2. пересоздаёт внутреннее состояние,
  3. воспроизводит журнал операций (брони/передачки),
  4. повторяет запрос.
- 📈 Доступен health-endpoint `GET /api/health` со статистикой:
  - количество восстановлений,
  - количество ошибок,
  - последняя ошибка,
  - число воспроизведённых событий.
- 🛠️ Ручной запуск самовосстановления: `POST /api/heal` или кнопка в UI.

## Остальной функционал

- построение последовательности маршрутов с учётом времени;
- фильтрация по водителю и городу;
- бронирование мест;
- оформление передачек;
- PWA-режим для iOS/Android.

## Запуск

```bash
python3 app.py
```

Откройте в браузере: `http://localhost:8080`
