# Личный умный помощник

Универсальный CLI-бот, который помогает вести задачи, заметки, привычки, покупки,
напоминания и шаблоны ответов. Данные сохраняются локально в JSON.

## Возможности

- Добавление и просмотр задач
- Отметка задачи как выполненной
- Добавление и просмотр заметок
- Привычки с сериями выполнения
- Список покупок
- Напоминания через N минут
- Шаблоны быстрых ответов
- Инструменты гибкости мышления (идеи и переформулирование)
- Дополнительные техники: ограничения, смена точки зрения, комбинирование областей
- Дополнительные техники: обратное мышление, лестница контекста, случайные триггеры
- Локальное хранение состояния

## Запуск

```bash
python src/assistant_bot.py
```

## Команды

- `help` — список команд
- `add-task <текст>` — добавить задачу
- `list-tasks` — показать задачи
- `done <номер>` — отметить задачу выполненной
- `add-note <заголовок> :: <тело>` — добавить заметку
- `list-notes` — показать заметки
- `add-habit <название> :: <частота>` — добавить привычку
- `list-habits` — показать привычки
- `habit-done <номер>` — отметить привычку
- `add-buy <название>` — добавить покупку
- `list-buys` — показать покупки
- `buy <номер>` — отметить покупку
- `remind <текст> :: <минуты>` — напоминание через N минут
- `list-reminders` — показать напоминания
- `remind-done <номер>` — отметить напоминание
- `add-template <ключ> :: <текст>` — сохранить шаблон ответа
- `template <ключ>` — получить шаблон
- `ideate <тема>` — идеи для гибкости мышления
- `reframe <ситуация>` — переформулировать ситуацию
- `constraints <тема>` — переосмыслить с ограничениями
- `perspective <тема>` — сменить точку зрения
- `combine <тема> :: <область>` — объединить области
- `invert <тема>` — подумать наоборот
- `ladder <тема>` — расширить контекст
- `randomize <тема>` — случайные триггеры
- `exit` — выход
