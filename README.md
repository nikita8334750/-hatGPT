# Логистическая программа для пассажирских перевозок

Веб-приложение с понятным интерфейсом для водителей и пассажиров.

## Что умеет

- строить последовательность маршрутов с учётом времени;
- показывать расписание водителя;
- показывать расписание по городу для пассажиров;
- бронировать места;
- оформлять передачки.

## Запуск

```bash
python3 app.py
```

Откройте в браузере: `http://localhost:8080`

## Тесты

```bash
python3 -m unittest -v
```
