# Логистическая программа для пассажирских перевозок

Функции программы:
- построение последовательности маршрутов с учётом времени отправления;
- расписание для водителей;
- расписание для пассажиров по городу;
- бронирование мест;
- оформление передачек (посылок на выбранный маршрут).

## Запуск

```bash
python3 app.py
```

## Тесты

```bash
python3 -m unittest -v
```
