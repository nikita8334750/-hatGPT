# Логистическая программа для пассажирских перевозок

Веб-приложение с адаптивным интерфейсом для водителей и пассажиров.

## Что умеет

- строить последовательность маршрутов с учётом времени;
- показывать расписание водителя;
- показывать расписание по городу для пассажиров;
- бронировать места;
- оформлять передачки;
- работать как мобильное PWA-приложение на iOS и Android.

## Запуск

```bash
python3 app.py
```

Откройте в браузере: `http://localhost:8080`

## Мобильная версия (iOS / Android)

1. Откройте приложение по URL на телефоне (в одной сети с сервером).
2. **Android (Chrome):** меню браузера → «Добавить на главный экран».  
3. **iOS (Safari):** «Поделиться» → «На экран “Домой”».  

После добавления приложение открывается как standalone-версия (почти как нативное).

## Тесты

python3 -m unittest -v
