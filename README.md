# Логистическая платформа пассажирских перевозок (Full Implementation)

Полноценная реализация enterprise-уровня: продуктовая витрина, операционный дашборд, self-healing ядро, коммерческие и административные сценарии.

## Что входит в «полную реализацию»

### 1) Операционное ядро перевозок
- смарт-построение маршрута с пересадками;
- табло отправлений по городам;
- отмена бронирований и передачек.

### 2) Администрирование маршрутов
- создание/обновление маршрута (`/api/route/upsert`);
- удаление маршрута (`/api/route/delete`);
- валидация на удаление маршрутов с активными сущностями.

### 3) Self-healing и устойчивость
- автоматическое восстановление сервиса при сбоях;
- replay журнала действий после восстановления;
- мониторинг через `GET /api/health`;
- ручной trigger восстановления `POST /api/heal`.

### 4) Аналитика и KPI
- endpoint `GET /api/analytics`;
- метрики в UI: заполняемость, конверсия, загрузка системы.

### 5) Коммерческий сайт и продажи
- enterprise-секции с SLA/безопасностью/аналитикой;
- 🖼️ визуальная фото-галерея и hero-баннер для более «живого» премиального интерфейса;
- форма запроса демо/внедрения (`POST /api/contact`), тикеты заявок;
- FAQ и юридический footer.

### 6) Совместимость для популярных браузеров в РФ
- fallback для сети (`fetch -> XHR`);
- безопасный localStorage;
- fallback для `backdrop-filter`;
- Lite-режим совместимости.
### 7) Data persistence и документация API
- состояние платформы сохраняется в `data_store.json` (события, health-статистика, заявки);
- при старте состояние восстанавливается автоматически;
- доступна документация endpoint-ов через `GET /api/docs`.

- бронирование мест;
- оформление передачек;
- PWA-режим для iOS/Android.

## Запуск

```bash
python3 app.py
```

Откройте в браузере: `http://localhost:8080`
