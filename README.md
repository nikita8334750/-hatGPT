# Логистическая программа для пассажирских перевозок

Платформа уровня enterprise: быстрый отклик, продвинутая навигация, self-healing и полноценная структура коммерческого сайта.

## Что добавлено как у «сайта за миллион долларов»

- 🧩 **Enterprise-блок** с ценностным предложением: SLA, безопасность, аналитика, customer success.
- 🧭 **Продуктовые секции**: операционный центр, управление, enterprise-предложение, support.
- 📞 **Коммерческая воронка**: форма «Запросить демо / консультацию» с тикетами (`POST /api/contact`).
- ❓ **FAQ блок** для снятия ключевых возражений.
- 🛡️ **Юридический footer** (privacy / terms / compliance).
## Надёжность и совместимость
- self-healing механизм с авто-восстановлением при ошибках;
- health API: `GET /api/health`;
- ручное восстановление: `POST /api/heal`;
- совместимость с браузерами, популярными в России (fallback для fetch/localStorage/CSS-эффектов);
- Lite-режим для слабых устройств.
  - количество ошибок,
  - последняя ошибка,
  - число воспроизведённых событий.
- 🛠️ Ручной запуск самовосстановления: `POST /api/heal` или кнопка в UI.

## Остальной функционал

- построение последовательности маршрутов с учётом времени;
- фильтрация по водителю и городу;
- бронирование мест;
- оформление передачек;
- PWA-режим для iOS/Android.

## Запуск

```bash
python3 app.py
```

Откройте в браузере: `http://localhost:8080`
